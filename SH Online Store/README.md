# SH Online Store (PHP + MySQL + Docker)

This is a dynamic online store web application developed in PHP and MySQL, running inside a Docker container. The project was created as part of the Web Programming coursework and fulfills all exam requirements.

## ✅ Key Features

- 🔐 Session & Cookie Management:
  - Login with "Remember Me" functionality
  - Captcha verification
  - Protected admin area

- 🧠 Object-Oriented Programming:
  - At least 2 PHP classes and 4 custom methods

- 🗂️ Form Handling:
  - File upload and validation
  - Store and retrieve image links from the database

- 🎨 User Interface:
  - Responsive layout using Bootstrap
  - Templates and form components

- 📚 JavaScript Features:
  - Minimum two JavaScript files for dynamic interaction
  - Canvas and SVG rendering

- 📍 Embedded Media:
  - Google Maps centered on UAIC
  - Embedded YouTube video
  - Embedded local MP4 video and MP3 audio file

- 📲 Social Media Integration:
  - Like & Share buttons (Facebook or other platforms)

## ⚙️ Technologies Used

- PHP 8+
- MySQL 8+
- Docker & Docker Compose
- HTML5, CSS3, JavaScript
- Bootstrap 5
- Google Maps API, YouTube Embed
