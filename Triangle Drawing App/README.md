# Triangle Drawing App (Java + AWT)

This is a simple graphical Java desktop application that allows users to interactively draw and manipulate triangles on a canvas.

## Features:
- Allows drawing triangles by clicking three points on the canvas.
- Supports colored backgrounds and triangle customization (colors, coordinates).
- Includes a compact graphical UI created using AWT and basic file resources.
- Designed to run from batch files (`start.bat`, `compilare.bat`) without the use of IDEs.

## How It Works:
- The user clicks three times on the drawing area to set the triangle’s vertices.
- The triangle is then rendered on the canvas.
- The interface includes buttons and background customization elements (e.g., background image and icon).

## Technologies Used:
- Java (no external libraries or frameworks)
- Java AWT (Abstract Window Toolkit)
- Windows batch scripting (`.bat` files for compile/run)

## Files:
- `Triunghi.java`: Main logic for triangle drawing and UI handling.
- `start.bat`, `compilare.bat`: Batch files for compilation and execution.
- `images/backg.jpg`, `images/ico.gif`: Background and icon for the UI.

This project was developed as part of the university coursework for programming in Java.
